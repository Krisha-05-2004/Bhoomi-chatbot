A RAG-based Farming AI chatbot that helps farmers with crop selection, soil insights, irrigation tips, and sustainable farming practices.
A smart agriculture chatbot designed to answer farming-related queries with reliable, data-driven insights and has language settings for kannada, telugu and hindi.
Built using Flask and RAG architecture, it enhances response accuracy through knowledge retrieval.
The platform aims to make farming information accessible, simple, and practical.
